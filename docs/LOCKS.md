# Locked screens

These screens are finished designs. Build them exactly as the prototype
shows: same layout, flow, motion and wording, nothing added. To change one,
ask the founder first, with a clickable prototype of the change. The written
lock files (backend repo, `docs/`) hold every signed word; where a lock file
and this list disagree, the lock file wins. The full earlier text of these
sections is in `docs/history/CLAUDE-2026-10-11.md`.

Three rules that always hold on these screens: the coach's Judge screen stays
blind (nothing about the moment is fetched until the coach answers); the
recording screens keep recording, saving and processing working at every
step; the consent screens always let a person agree and record.
