# Locked screens

> **Label: In force** · one of the rules, read in N95's order. Every doc and its label: [`README.md`](../README.md) (N106).

These screens are finished designs. Build them exactly as the prototype
shows: same layout, flow, motion and wording, nothing added. To change one,
ask the founder first, with a clickable prototype of the change. The rules
pages, in the frontend repo's `docs/flows/`, hold the signed words, folded in
verbatim from the lock files, which are now history (N107; the founder lock
for the coach panel and the learning machine, L1 to L9, stays In force).
Where two disagree, read them in N95's order: the decisions log, then the
contract, then this list and the rules pages. The Feedback walk and the chat
have one page in the frontend repo instead, [`docs/flows/feedback-walk-and-chat.md`](https://github.com/wilplus/frontend-cursor/blob/main/docs/flows/feedback-walk-and-chat.md),
and the coach panel [`docs/flows/coach-panel.md`](https://github.com/wilplus/frontend-cursor/blob/main/docs/flows/coach-panel.md),
each of which grows by lines (2026-10-20). The full earlier text of these
sections is in [`docs/history/CLAUDE-2026-10-11.md`](history/CLAUDE-2026-10-11.md).
